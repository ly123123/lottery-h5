# 智选号码 · 双色球 & 大乐透

一个纯前端、可离线、可安装到 iPhone 主屏幕的移动端 H5 应用。基于**近两年真实开奖数据**做归类统计、组合优化选号，并对**注数与投注金额做严格核算**。

![图标](public/icons/icon-192.png)

## 功能

### 1. 数据分析（近两年真实开奖）
- 双色球 **307 期**（2024-11-03 ~ 2026-11-12）、大乐透 **306 期**（2024-11-06 ~ 2026-11-14）
- 数据源：中国福彩 / 中国体彩官方开奖公告接口
- 号码热度网格（近 30 期出现次数）、冷热号、遗漏值
- 和值分布、奇偶比、大小比、三区分布、连号、重号、AC 值、跨度
- 各奖级中奖条件与理论概率（1/17,721,088 等精确到组合数）

### 2. 智能预测（五模型集成）
| 模型 | 说明 |
| --- | --- |
| 近期热度 | 指数加权频率，半衰期 25 期 |
| 贝叶斯后验 | Beta 平滑的条件频率 |
| 遗漏回归 | 当前遗漏 / 平均遗漏 的偏离度 |
| 马尔可夫转移 | 一阶转移概率（上期出现与否） |
| 岭回归多因子 | 5 维特征 + 闭式解学习，增量构造样本 |

集成后再做**组合结构优化**：
- 和值限定在历史 10%~90% 分位
- 奇偶、大小比例贴近历史分布
- 限制连号与超短跨度
- 对生日号、全小号、等差数列等"大众化组合"降权，降低与他人重复导致的奖金摊薄

### 3. 回测验证（诚实呈现）
滚动回测（walk-forward），每个窗口只用该窗口之前的数据训练，预测下一期后与真实开奖号比对，并做 **z 显著性检验**。

结论符合数学本质：**彩票独立随机，任何算法都无法提高中奖概率**。回测中的差异全部落在统计噪声范围内（|z| < 1.96）。本应用的价值在于数据归类、组合结构优化与金额精确核算，而不是"预测中奖号"。

### 4. 金额精确核算
全部使用整数组合数计算，不经过浮点累加：

```
双色球：注数 = C(红球个数, 6) × 蓝球个数
        金额 = 注数 × 2 元 × 倍数

大乐透：注数 = C(前区个数, 5) × C(后区个数, 2)
        金额 = 注数 × (2 + 追加 1) 元 × 倍数
```

内置校验：单票 20,000 元上限、单票 10,000 注上限、倍数 1~99，超限给出拆分方案。

已验证用例：
| 玩法 | 注数 | 金额 |
| --- | --- | --- |
| 双色球 单式 6+1 | 1 | 2 元 |
| 双色球 复式 8+2 | 56 | 112 元 |
| 双色球 复式 10+3 × 5 倍 | 630 | 6,300 元 |
| 大乐透 单式 5+2 追加 | 1 | 3 元 |
| 大乐透 复式 7+3 | 63 | 126 元 |
| 大乐透 复式 8+4 × 2 倍（追加） | 336 | 2,016 元 |

### 5. 大乐透新规则适配
2026-02-02（第 26014 期）起，大乐透由 9 个奖级合并为 7 个奖级。本项目用 **117 期真实开奖数据反解校验**奖级映射：

| 奖级 | 中奖条件 | 固定奖金（奖池≥8亿时） |
| --- | --- | --- |
| 一等奖 | 5+2 | 浮动 |
| 二等奖 | 5+1 | 浮动 |
| 三等奖 | 5+0、4+2 | 5,000（6,666） |
| 四等奖 | 4+1 | 300（380） |
| 五等奖 | 4+0、3+2 | 150（200） |
| 六等奖 | 1+2 | 15（18） |
| 七等奖 | 3+1、3+0、2+2、2+1、0+2 | 5（7） |

校验结果：各级概率与理论值相对误差 < 6%，七等奖中奖率 1/16.8，与官方公布的 1/16.6 吻合。

## 开发

```bash
npm install
npm run dev          # 本地开发
npm run build        # 类型检查 + 构建（输出 dist/）
npm run fetch        # 重新抓取官方开奖数据
node scripts/verify.mjs   # 金额与奖级概率校验
```

技术栈：Vite 5 + React 18 + TypeScript，无 UI 框架、无图表库，gzip 后约 77 KB。
PWA：手写 Service Worker（导航网络优先 + 静态资源缓存优先），支持完全离线使用。

## 部署到 iPhone

### GitHub Pages 自动部署
1. 推送到 `main` 分支
2. GitHub Actions 自动构建并发布
3. 仓库 Settings → Pages → Source 选择 **GitHub Actions**

### 在 iPhone 上安装为 App
1. 用 Safari 打开 Pages 地址
2. 点击底部「分享」→「添加到主屏幕」
3. 之后从主屏幕图标启动，即为全屏无地址栏的独立 App，断网也能用
