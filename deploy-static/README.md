# 智选号码 · 双色球 & 大乐透

移动端 H5 选号应用，纯静态、可离线、可安装到 iPhone 主屏幕。

- 近两年真实开奖数据（双色球 307 期 / 大乐透 306 期）
- 五模型集成选号 + 滚动回测 + 显著性检验
- 单式/复式注数与金额精确核算（组合数严格计算）
- PWA 离线可用

## 部署

Settings → Pages → Source：
- 选 **Deploy from a branch** → `main` / `/ (root)`，或
- 选 **GitHub Actions**（本仓库已含 `pages.yml`）

访问：`https://<用户名>.github.io/<仓库名>/`

## iPhone 安装

Safari 打开上面的地址 → 底部「分享」→「添加到主屏幕」→「添加」。

> 彩票开奖完全随机，本应用仅供娱乐参考，不构成投注建议。
